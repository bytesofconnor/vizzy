# Vizzy Roadmap
Updated: 2026-10-24 · Owner: Vizzy · North star: pasteable, opinionated charts for writers (link + PNG), chart excellence before My BI.

## Open (ranked; knock off from the top)
1. **Clear generate button on the homepage** — Visitors see where to start within one second. Check: primary CTA visible above the fold on phone and desktop; exactly one primary button.
2. **Pricing line on the homepage** — Show "3 free, then $8 for 25" so price is never a surprise. Check: pricing copy visible without scrolling on desktop hero.
3. **Sharper outcome headline** — Lead with what the writer gets: a publish-ready chart as a link or PNG. Check: headline names the outcome, not a vague BI pitch.
4. **Personal chart library** — Every chart you make is saved and easy to find again (retention). Check: signed-in user can list prior charts and reopen one.
5. **Edit charts in place** — Tweak a published chart without remaking it; embeds update. Check: edit flow changes the same URL/PNG without minting a new id unless intended.
6. **Agent-ready create-chart API** — Prompt or data in → link + PNG + source out. Check: documented public compose/publish path works for an agent with no browser.
7. **MCP connector** — Agents in Muse/Claude/ChatGPT can make Vizzy charts. Check: MCP tools listed and one end-to-end create works.
8. **Source picking with Jev** — Choose the best official source automatically; show receipts. Check: chart carries source label/url when Jev picks.
9. **My BI live pins** — Charts that stay updated, pinned to a personal dashboard. Check: pinned chart refreshes without manual republish.
