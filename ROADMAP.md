## Shipped
- **Match the date note to the axis** — 2026-10-29. The note states the first and last year on the rows. Extreme poverty 1990-2023 ends at 2023, and the 2023 point stays 10.5%. US federal funds rate since 2020 is a line from 2020. Antarctic sea ice for 1979-2023 does not run the axis to 2026. [#53](https://github.com/bytesofconnor/vizzy/pull/53).
- **Show a sparse or empty chart as unfinished** — 2026-10-24. Unsourced estimate and example sketches draw dashed Unfinished bars and hide the y scale. Unattested empty categories say empty and draw no bar. A sourced 0 still paints 0. [#50](https://github.com/bytesofconnor/vizzy/pull/50).
- **Keep source labels honest** — 2026-10-24. Wikipedia catalog charts are not graded official. A wiki table whose kept rows share one year puts that year in the source label and the title when the prompt lacks it. An unsourced estimate hides the y-axis scale and the bar value labels. Bar heights may still exist in the data. Unfinished presentation shipped in [#50](https://github.com/bytesofconnor/vizzy/pull/50). [#48](https://github.com/bytesofconnor/vizzy/pull/48).

Just send it mints the original prompt and does not ask again. A clear prompt still generates with no interrupt, such as Bitcoin price from March to June 2021 or US unemployment since 2019. [#46](https://github.com/bytesofconnor/vizzy/pull/46).

## Later, after reliability
- CHART.md taste and eval loop — after the Open reliability items are cleared. A machine-readable taste file names chart-type rules, receipt placement, and anti-patterns. Golden evals check charts against that file. The rules live in code, modeled on Vercel DESIGN.md and a code-level design system.
- Personal chart library — a growth bet, not a fix for a chart that fails.
- Edit a published chart at the same URL — the open chart can already be revised. A stable public id is later.
- MCP and a Muse-style host skill — a drop-in Vizzy skill, not a marketplace. It returns a chart URL and a PNG when Muse, or a similar host, calls it mid-task. The chart is a trust signal. `apps/mcp` already lists schema, validate, compile, and publish. More hosts come later.
- Source picking with Jev — optional, and only after retrieval. It arbitrates sources the way a citation check or RAG passage gating does. It does not discover sources. Catalog and matcher fixes that already shipped come first.
- My BI live pins.

## Not doing
- Product Hunt launch — premature until the homepage converts and the chart loop is proven.
- Broad "ChatGPT for BI" positioning — Vizzy is chart excellence first; My BI is later.
- Muse marketplace brokerage — Vizzy is not a Muse broker.
- "UI is gone" — the human-readable chart stays. Writers and agents both read that page.
